About Project

The Examination Result Processing System calculates student results and displays them in a clear format. This website uses HTML, CSS, and JavaScript. The related C++ project demonstrates object-oriented programming concepts.

Aim

To simplify examination result calculation.

Benefits

Reduces manual calculations and saves time.

Classes and Objects

Organize student data and result processing in OOP.

Constructor

Initializes an object when it is created.

Inheritance

Allows one class to reuse another class's features.

Function Overloading

Uses the same function name with different parameters.

Grade Calculation

Calculates percentage and assigns a grade.

Pass/Fail Checking

Checks whether the student passes every subject.

Input Validation

Checks that marks are whole numbers between 0 and 50.

Technologies: HTML, CSS, JavaScript and C++ OOP concepts.

Note: This website calculates results in the browser and does not save student records to a database.
